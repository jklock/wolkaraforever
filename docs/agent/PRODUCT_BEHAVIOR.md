# Product behavior

> Verified: 2026-11-13 · Source: `3c33543` · Proof: launcher source, localized strings, and focused suites

WolkaraForever lets a user choose a Forever region and game language; download, resume, verify, repair, and update game data; then start the unchanged executable through an available execution mode. The launcher also supports app localization, interface-mode selection, add-ons, UI recovery, keyboard/controller/touch input, dictation, and diagnostics.

The launcher records only managed add-ons for removal, stages updates and restores before replacement, and keeps diagnostics redacted. An API key is device-local and optional; browser or Files acquisition remains available where appropriate.
