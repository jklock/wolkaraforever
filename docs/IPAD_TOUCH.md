# Play by touch on iPad (iPad touch and TouchPlay)

> Verified: 2026-11-26 · Source: `555668e`

**iPad touch** is an interface mode for iPads played with the TouchPlay add-on. The game's own
buttons, drawn by TouchPlay, are the controls, so the on-screen controller is not shown. This page
covers the mode, its chat and its password keyboard.

## Choose iPad touch

1. Install the TouchPlay add-on with the **Add-on Manager**. It is not bundled with WolkaraForever:
   get its ZIP from its releases page, https://github.com/myi1/TouchPlay/releases (MIT), then import it from Files.
2. Start the game, and in the game use TouchPlay's **Menu › Save settings** once, so TouchPlay writes
   its button list.
3. Open **Launcher Manager**, choose **Interface Mode**, and pick **iPad touch**. Automatic never picks
   it; it is always chosen on purpose. The next game start reads TouchPlay's buttons.

The mode list has five choices: **Automatic**, **iPadOS**, **iOS**, **iOS on Duo** and **iPad
touch**. If the game closes unexpectedly twice in a row in iPad touch, WolkaraForever goes back to
iPadOS and tells you once. If TouchPlay has not saved its buttons yet, the game says "Touch buttons
not found" for a few seconds. Touches are then plain clicks, and there is no walk stick.

## Play by touch

- **Buttons.** A touched TouchPlay button lights up at once, with a soft pale-gold glow in the
  button's shape that is gone a moment after you lift.
  - Lift your finger on the button to use it.
  - Keep the finger there to fill a ring and open the button's card.
  - Slide off a spell to aim it with your finger. Let go on the ground to cast there, or on Cancel
    (or any other button) to stop.
- **The world.**
  - Tap to select. Tap again nearby to talk, loot or attack.
  - Keep a finger still to see what is under it.
  - Drag to look around, and pinch to zoom.
  - A touch right at the screen's edge does nothing.
- **Walking.** Put a thumb in the outer third of the screen, below the top band of cards, on the side
  away from your spells. With TouchPlay set left-handed, that is the right side. The walk stick
  appears under the thumb.
  - To keep running, slide up past the ring onto the lock above it, hold for a moment, then let go.
  - Touch the stick area or the lock again to stop.
  - Two fingers at once are a pinch, not a walk.
  - Walking uses the game's own W, S, A and D keys, so keep those bound to moving.
- **Windows.** With a game window open (bags, character, a vendor), taps are plain clicks and a still
  hold is a right click. The walk stick keeps working in its own corner.
- **Only in the world.** On the login and character screens, every touch is the game's own plain
  touch. TouchPlay tells WolkaraForever when you enter or leave the world.
- **Leaving the app.** Putting the app away (a call, Control Centre, Home) lets go of every key a
  finger holds. If the app went to the background during a touch or a screen lock, that old finger
  cannot drag or click on return: lift it and tap again.
- **Trackpad.** The toolbar's cursor button turns a trackpad on instead. In iPad touch that switch is
  its own, off until you turn it on there.

## Chat and the password

**Chat.** Tap TouchPlay's chat strip, or the toolbar's keyboard button.

1. Above the keys, pick Say, Party, Guild, Whisper (a reply to the last whisper) or Yell, if you like.
2. Type.
3. Press the gold **Send**, or the keyboard's Send key.

Tap the game to close the chat without sending. In iPad touch this is the chat. The review-then-send
Chat Composer of the other interfaces is not used here. The chat strip opens with one tap over
TouchPlay's map and other sheets too. Over the game's own windows, the strip stays a plain game tap.

**A game text box.** To type into a focused game text box, such as map search, tap the box. Then tap
the toolbar's keyboard button while a sheet or window is open, or while you are at the character
list.

- Characters reach the game as you type, and Done closes the keyboard.
- A tap on the game closes the keyboard and still selects what you tapped.
- In the world, the toolbar button opens the chat instead.
- With no game box focused, keys typed over a game window act as game key presses. If a key closes
  the last window, further keys reach the world until TouchPlay's signal settles, usually well under
  a second.

**The password.** At the login screen, the password box brings up the keyboard, and the game slides
up so the box stays in sight.

- Type the password: each key goes into the game's box as you type it, and Return logs in.
- Password AutoFill and the saved-password key are not offered in iPad touch.
- WolkaraForever never keeps, logs or copies the password.
- In the account-name box, the keyboard's key reads **Next** and moves to the password box. It never
  logs in.
- If the keyboard is gone while the password box still has the cursor, the toolbar's keyboard button
  brings it back.
