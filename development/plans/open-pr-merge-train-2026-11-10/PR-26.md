## Acceptance contracts

### Mode isolation

Every refinement reads AKInterfaceModeIsMobile() at its decision point. Do not add a parallel
AKDuoInterface, hardware-model default, or gamepad-layout proxy. Test:

1. missing key → iPadOS;
2. malformed/unknown key → iPadOS;
3. ipados → exact Standard behavior;
4. ios → Duo behavior.

Changing modes releases held inputs, preserves add-on install state, and leaves Launcher
Manager/recommendation behavior unchanged. It must not mutate a game preference, archive,
manifest, or add-on directory.

### Input correctness

For every retained touch feature, define point/normalized geometry and test positive plus
adjacent-negative regions. Prove that:

- pass-through occurs only outside every owned control;
- stick, corner jump, add-on exclusion, and toolbar never compete for one touch;
- auto-run has explicit arm, confirmation, cancellation, and stop paths;
- lost/cancelled touch, keyboard appearance, hide, disconnect, backgrounding, and mode change
  release every key/controller state exactly once;
- pinch ignores touches begun on a WolkaraForever control while Standard gestures are unchanged;
- labels/identifiers are stable, localized, and reachable at largest text.

Do not manually forward UIKit UITouch objects to fake tap-through. Keep lifecycle ownership
with the app's hit-test/gesture routing.

### Add-on upgrade

Treat 1.0.4 as a product upgrade, not a source dump:

- inventory old/new TOC entries; every Lua/XML file is reviewed, listed, and Lua-5.1 compilable;
- preserve saved-variable migration and existing 0.9.1 layouts;
- add focused coverage for retained fan/quick-bar/edit/chat/frame behavior and unavailable or
  secret game API values;
- rebuild ZIP/JSON using package_addon_zip.py; committed artifacts must match exactly;
- prove the production verifier accepts the new pair and refuses malformed, stale, traversal,
  extra-file, missing-file, and wrong-version fixtures;
- keep installation explicit: after choosing **iOS on Duo**, the user chooses Install in
  Add-On Manager; a mode change never upgrades the package.
